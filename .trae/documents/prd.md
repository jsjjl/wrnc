## 1. 产品概述

邗江区无人农场智慧管理平台是一个面向农业管理者的综合展示与监控平台，集成农情监测、作物感知、视频监控、智能设备管理、作业调度等核心功能，实现农田"四情"（墒情、虫情、苗情、灾情）的实时感知与智能决策，推动农业生产无人化、智能化。

- 目标用户：农场管理者、农技人员、政府农业管理部门
- 核心价值：通过物联网设备与AI技术，实现农业生产全流程数字化管理与智能决策

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 农场管理员 | 系统分配 | 全部功能访问、设备管理、作业调度、报告审批 |
| 农技人员 | 系统分配 | 查看监测数据、异常预警、处置建议 |
| 访客 | 无需注册 | 查看公开的农场概况与生产状态 |

### 2.2 功能模块

1. **首页总览**：农场全景概览、核心指标展示、预警信息、快捷入口
2. **农情监测**：气象、土壤、虫情、苗情四情数据实时展示与历史趋势
3. **视频监控**：鹰眼全景、球机监控、巡检无人车实时画面
4. **智能设备**：设备状态总览、远程控制、编组管理
5. **作业管理**：灌溉调度、农机作业、植保无人机、作业轨迹与完成分析
6. **预警中心**：异常预警、处置处方、阶段性报告
7. **数据报告**：日报/周报/阶段报告、产量预测、物候期追踪

## 3. 核心流程

### 3.1 日常监测流程

用户打开平台 → 查看首页总览核心指标 → 点击四情卡片进入详情 → 查看历史趋势与当前数据 → 系统自动生成日报

### 3.2 异常处置流程

设备/数据异常 → 系统触发预警 → 推送预警通知 → 用户查看预警详情 → 系统生成处置处方 → 用户确认执行 → 设备执行/人工干预 → 结果反馈与记录

### 3.3 作业调度流程

用户创建作业任务 → 系统规划作业路径 → 下发至农机/无人机 → 实时监控作业过程 → 作业完成分析 → 前后对比与数据留存

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：科技绿（#1DB954）+ 深空蓝（#0A1628），体现智慧农业与科技感
- **辅助色**：预警橙（#FF8C00）、数据蓝（#00B4D8）、土壤棕（#8B6914）
- **按钮风格**：圆角8px，hover时发光效果，主按钮填充、次按钮描边
- **字体**：标题使用思源黑体/Noto Sans SC Bold，正文使用Noto Sans SC Regular
- **布局风格**：左侧导航栏 + 顶部信息栏 + 主内容区，卡片式布局
- **图标风格**：线性图标，2px描边，与整体科技感一致
- **动效**：数据卡片入场动画、数字滚动效果、图表渐显、预警闪烁

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页总览 | 农场全景卡片 | 深色渐变背景，大数字+图标，入场动画，发光边框 |
| 首页总览 | 四情概览 | 4列卡片（PC）/ 2列（平板）/ 1列（手机），图标+数值+趋势箭头 |
| 首页总览 | 预警快报 | 橙色高亮条目，滚动动画，点击展开详情 |
| 首页总览 | 作业进度 | 环形进度条，颜色编码（进行中/已完成/待执行） |
| 首页总览 | 实时视频预览 | 16:9缩略图，悬浮播放按钮，边框发光 |
| 农情监测 | 气象监测 | 折线图+当前值大字，24h趋势 |
| 农情监测 | 土壤监测 | 多层土壤剖面图，颜色映射温湿度 |
| 农情监测 | 虫情监测 | 虫体图片+计数，蛾量柱状图 |
| 视频监控 | 多路画面 | 2x2网格（PC）/ 单路全屏（手机），画面切换动画 |

| 作业管理 | 灌溉管理 | 田块地图+灌溉进度条，片区编组面板 |
| 预警中心 | 预警列表 | 时间线布局，严重程度颜色编码，展开处置建议 |

### 4.3 响应式设计

- **桌面端（≥1200px）**：左侧固定导航 + 主内容区多列布局，视频2x2网格，图表宽幅展示
- **平板端（768px-1199px）**：顶部折叠导航 + 内容区2列布局，视频单路/双路切换
- **手机端（<768px）**：底部Tab导航 + 单列布局，视频单路全屏，卡片纵向堆叠
- **触控优化**：按钮最小44px触控区域，滑动手势切换视频/图表，下拉刷新数据

### 4.4 数据展示终端适配

平台数据需适配多种展示终端：
- **指挥中心大屏**：5.12m×2.88m LED显示屏，深色主题，大字体，关键指标突出
- **PAD终端**：6GB运行内存移动管理终端，触控优化，作业管理重点
- **手机**：轻量化展示，预警推送，快速查看
- **户外LED屏**：P2.5全彩，四情监测农情数据滚动展示
- **55寸触摸一体机**：生产状况展示，交互式查询
- **二维码**：田块标识牌扫码查看生产情况
