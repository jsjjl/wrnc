## 1. 产品概述

邗江区无人农场农产品溯源系统，包含消费者端和农管人员端两个独立页面，实现从田间到餐桌的全链路溯源可视化。消费者端以优雅舒适的体验展示产品溯源信息，农管人员端以高科技风格提供全链路溯源管理与AI智能分析。

- 消费者端：让消费者通过扫码/输入溯源码，直观了解农产品的产地、种植、加工、物流全流程，建立消费信任
- 农管人员端：为农业管理人员提供溯源数据管理、质量监控、风险预警和AI决策支持

## 2. 核心功能

### 2.1 用户角色

| 角色 | 访问方式 | 核心权限 |
|------|----------|----------|
| 消费者 | 扫码/输入溯源码 | 查看产品溯源信息、AI问答 |
| 农管人员 | 登录后台 | 管理溯源数据、质量监控、AI分析 |

### 2.2 消费者端功能模块

1. **溯源查询首页**：溯源码输入/扫码入口、热门产品展示、农场故事
2. **产品溯源详情**：产品基本信息、产地信息、种植过程时间线、质检报告、物流追踪
3. **AI溯源助手**：智能问答、产品推荐、营养分析

### 2.3 农管人员端功能模块

1. **溯源总览仪表盘**：溯源数据统计、实时监控、异常预警
2. **批次管理**：产品批次列表、批次详情、溯源链路编辑
3. **质量监控**：质检数据看板、不合格预警、检测报告管理
4. **供应链追踪**：物流节点追踪、温控监测、仓储管理
5. **AI智能分析**：风险预测、异常检测、智能决策建议

## 3. 核心流程

### 消费者溯源查询流程

消费者打开页面 → 输入/扫码溯源码 → 展示产品基本信息 → 滑动查看种植过程时间线 → 查看质检报告 → 查看物流追踪 → AI助手咨询

```mermaid
    "输入/扫码溯源码" --> "展示产品基本信息"
    "展示产品基本信息" --> "查看产地信息"
    "查看产地信息" --> "种植过程时间线"
    "种植过程时间线" --> "质检报告"
    "质检报告" --> "物流追踪"
    "物流追踪" --> "AI助手咨询"

```

登录系统 → 查看总览仪表盘 → 异常预警处理 → 批次管理/质检审核 → AI分析决策 → 生成报告

## 4. 用户界面设计

### 4.1 消费者端设计风格

- **主色调**：自然绿(#2D8B4E) + 暖金色(#D4A843) + 米白(#FAFAF5)
- **辅助色**：浅绿(#E8F5E9)、暖灰(#F5F0EB)、深棕(#5D4037)
- **按钮风格**：圆角胶囊按钮，柔和阴影，微动效
- **字体**：思源宋体(Noto Serif SC)标题 + Noto Sans SC正文，营造自然人文感
- **布局风格**：卡片式流式布局，大留白，呼吸感强
- **动画**：淡入滑动、视差滚动、时间线渐进展开
- **整体风格**：自然、温暖、信任感、高端有机品牌感

### 4.2 农管人员端设计风格

- **主色调**：科技蓝(#00D4FF) + 深空蓝(#0A1628) + 警示橙(#FF6B35)
- **辅助色**：暗蓝(#111D33)、边框蓝(#1E3A5F)、成功绿(#1DB954)
- **按钮风格**：扁平化、发光边框、hover发光效果
- **字体**：Noto Sans SC，等宽数字字体用于数据展示
- **布局风格**：仪表盘网格布局、侧边导航、数据面板
- **动画**：数据跳动、脉冲发光、扫描线、粒子背景
- **整体风格**：赛博朋克、数据可视化、指挥中心感

### 4.3 响应式设计

- 桌面端(≥1200px)：完整布局，多列网格
- 平板端(768px-1199px)：适配布局，两列/单列切换
- 手机端(<768px)：单列布局，底部导航，触摸优化

### 4.4 AI功能设计

#### 消费者端AI助手
- 右下角悬浮按钮，点击展开对话面板
- 预设快捷问题：营养分析、食用建议、存储方法、真伪验证
- 温暖友好的对话风格，回答包含emoji和格式化内容

#### 农管人员端AI分析
- 侧边AI分析面板，可展开全屏
- 预设分析场景：风险预测、异常检测、趋势分析、决策建议
- 专业数据驱动的分析结果，包含图表和建议
